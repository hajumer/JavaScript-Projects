Cargo Manifest Validator

About This Project

This project validates cargo manifest information using JavaScript. It checks whether important properties are present and whether their values are valid.

The program can also convert cargo weight from pounds to kilograms without changing the original manifest object.

In this project, I practiced JavaScript objects, functions, object copying, validation, Number.isInteger(), Number.isNaN(), trim(), Object.keys(), conditionals, and unit conversion.

Manifest Information

A valid cargo manifest includes:

  • Container ID
  • Destination
  • Weight
  • Weight unit
  • Hazardous material status

Weight Conversion

Pounds are converted to kilograms using: 1 lb = 0.45 kg
