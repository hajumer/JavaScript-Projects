Lunch Picker Program

About This Project

This project is a simple Lunch Picker Program built with JavaScript. It allows lunch items to be added, removed, displayed, and randomly selected.

In this project, I practiced JavaScript arrays, functions, push(), unshift(), pop(), shift(), join(), Math.random(), Math.floor(), if statements, and console output.

What This Program Can Do

Add a lunch item to the start or end of the menu.

Remove a lunch item from the start or end of the menu.

Display all lunch menu items.

Select a random lunch from the menu.
