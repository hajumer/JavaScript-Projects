Truncate a String

About This Project

This project shortens a string when it is longer than a given length. If the string is too long, three dots are added at the end.

In this project, I practiced JavaScript functions, parameters, string length, if statements, return statements, and the slice() method.

Example

"A-tisket a-tasket A green and yellow basket" with a limit of 8 becomes "A-tisket..."
