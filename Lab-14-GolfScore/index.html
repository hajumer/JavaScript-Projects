Golf Score Translator

About This Project

This project translates a golfer's score into the correct golf nickname based on the par and number of strokes.

In this project, I practiced JavaScript functions, parameters, if/else statements, comparison operators, and return statements.

Golf Score Rules

1 stroke → Hole-in-one!

Two or more under par → Eagle

One under par → Birdie

Equal to par → Par

One over par → Bogey

Two over par → Double Bogey

Three or more over par → Go Home!
